Included messages use durable reservations.

Tested

An account row lock protects the count-and-reserve transaction across concurrent requests. Completed answers consume one allowance, retries with the same request identifier are deduplicated, failures can release the allowance, and closing the client does not refund a completed answer.

Scope and implementation details

The wrapped user actions are chat, note AI, note composition, fresh verse insight, generated reading plans and memory summaries. Cached responses do not invoke inference and do not reserve a message; tools, narration, titles and memory work in the same request share its reservation and cost ledger.

Daily windows use UTC, displayed locally. Pro monthly windows follow the stored billing period; complimentary Pro uses calendar months. Requests have an output ceiling, a model-call ceiling, a serialized prompt-size limit and a separate repeated-failure limit; these bounds are not a guarantee of total product cost.

New models: BillingSubscription, BillingEvent, AiUsageRequest and AiPreference. Payer preferences are isolated from existing User queries until activation. Standalone automatic Luna utilities have their own daily budget and ledger without consuming chat messages. Source: src/lib/billing/usage.ts, plans.ts, stripe.ts, src/app/api/billing and the shared provider resolver. Checkout stays closed until configuration is complete.

Launch gate

The server verifies that the configured Price is active, USD, monthly and exactly $15. Checkout and Portal require authentication and reject cross-site browser writes; concurrent checkout requests reuse an open session, and a browser success redirect never grants Pro.

Billing behavior

Signed events are deduplicated and current Stripe subscription state is retrieved after a reconciliation lock. Paid activation, cancellation at period end, unpaid invoices, out-of-order events, dispute holds, resolved disputes and full current-period refunds have fixture-backed coverage against real Postgres writes.

A full refund of the current period or a lost dispute cancels that subscription; a pending dispute holds access. Complex payments spanning multiple invoices fail closed for explicit reconciliation. Complimentary and owner access remains independent.

New paid audio is separately gated by SUREWORD_PRO_AUDIO_ENABLED. Existing complimentary audio grants remain intact; this prevents opening an unmeasured synthesis workload merely by enabling chat subscriptions.
