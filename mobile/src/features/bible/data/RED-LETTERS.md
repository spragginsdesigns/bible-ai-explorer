# KJV speech annotations

`kjv-red-letters.json` is a presentation sidecar to the existing KJV, derived
from eBible.org's USFM `\wj …\wj*` markers. We retain the bundled Scripture
verbatim. Red lettering follows this source edition's editorial speech
boundaries; it is not generated by AI or inferred from references to Jesus.

Source: https://ebible.org/Scriptures/eng-kjv_usfm.zip
Attribution and rights: https://ebible.org/eng-kjv/copyright.htm
The source credits CrossWire Bible Society and eBible.org and declares the
text public domain, with a separate notice about UK printing rights.
The companion `.source.json` records the downloaded archive's SHA-256.

Regenerate from the repository root:

```sh
curl --fail --location https://ebible.org/Scriptures/eng-kjv_usfm.zip -o /tmp/eng-kjv_usfm.zip
python3 scripts/bible/build-kjv-red-letters.py /tmp/eng-kjv_usfm.zip
npm --prefix mobile test -- src/features/bible/redLetters.test.ts
```

The importer checks all marked verses against bundled text. It ignores
punctuation, whitespace and case for alignment; expands the æ ligature; and
uses nine explicit, reference-specific edition aliases documented in the
script. Any other text mismatch aborts generation. The result stores exact
bundled text with half-open character ranges; runtime text equality prevents
stale offsets being applied after a text update.

Coverage: 2,028 verses in Matthew, Mark, Luke, John, Acts, 1 Corinthians,
2 Corinthians and Revelation. Tests cover mixed narration/dialogue, a return
to narration, italics, all stored ranges, unchanged copy text, and translation
isolation. The web and Android readers and the public chapter API consume
these annotations. Apple's SwiftUI readers have not yet been wired to them.

## NKJV source gate

The current `bolls.life/get-chapter/NKJV/43/3/` response has verse text and
italics but no speech boundaries. Do not apply KJV ranges to NKJV or color
whole verses based on a speaker list. NKJV requires a provider-authorized
annotated edition and validation against that exact edition. API.Bible lists
NKJV in its catalog (https://docs.api.bible/), but speech markup and license
entitlement still need verification before adopting it. This change does not
claim NKJV red-letter support.
